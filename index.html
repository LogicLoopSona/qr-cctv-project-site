QR-Based CCTV Access System

A smart project prototype designed to demonstrate secure, request-based and time-limited CCTV video access using QR codes and administrator approval.

Explore Project

About Our Project

The QR-Based CCTV Access System is a web application prototype that allows users to request access to a selected CCTV camera by scanning a QR code. An administrator can review the request and approve or reject it. Approved access is provided for a limited time.

This is an academic demonstration prototype, not a certified CCTV security product. Do not use it with real or sensitive camera footage.

Key Features

QR Code Generation

Generate a unique QR code associated with a camera.

User Access Request

Users can submit requests for camera access.

Admin Approval

Administrator can approve or reject access requests.

Temporary Access

Approved users receive time-limited video access.

OTP Verification

A mock OTP step demonstrates an additional verification stage.

Audit Events

Basic application events are recorded for demonstration.

How It Works

1. Admin adds a CCTV camera and generates its QR code.
2. User scans the QR code.
3. User submits an access request.
4. Admin reviews and approves or rejects the request.
5. Approved user gets temporary access to the demo video.

Future Scope

Future improvements may include real OTP integration, stronger authentication, secure audit storage, improved user roles, durable video storage and additional security testing.

Current limitations include mock OTP, spoofable browser location and basic audit logging. Browser restrictions cannot prevent screen recording.
